# Conversor de Temperatura

Conversor simples entre graus **Celsius** e **Fahrenheit**, feito com HTML, CSS e JavaScript puro como atividade de faculdade em 2024.

Todo o código foi escrito à mão, sem frameworks, bibliotecas ou ferramentas de IA.

🔗 **Acesse:** [irlamfernandes.github.io/conversor-temperatura](https://irlamfernandes.github.io/conversor-temperatura/)

## Como funciona

1. Digite uma temperatura no campo.
2. Clique em **Converter para Graus Celsius** se o valor estiver em Fahrenheit, ou em **Converter para Graus Fahrenheit** se estiver em Celsius.
3. O resultado aparece logo abaixo, com duas casas decimais.

Fórmulas usadas:

- °C = (°F − 32) × 5/9
- °F = (°C × 9/5) + 32

## Tecnologias

- HTML5
- CSS3
- JavaScript: manipulação do DOM com `getElementById` e eventos `onclick`

## Como executar

Acesse o link acima ou rode localmente, sem instalar nada:

```bash
git clone https://github.com/Irlamfernandes/conversor-temperatura.git
cd conversor-temperatura
```

Depois, abra o arquivo `index.html` no navegador.

## Estrutura

```

├── style.css    # estilos

```
